# 按范围验收与只读审查

仅检查本次涉及的项，缺失能力不自动变成新功能需求。Review 给出具体位置、影响和建议，不自动修复；实现模式才在授权范围内修改并重测。

## 共通关口

- 输入来自真实代码/契约；新增依赖、全局迁移、后端变化不超范围。
- App/布局不吞页面业务；接口参数/响应和领域共用类型默认 typings/<domain>.ts，显式导入；props/UI 类型就近，无重复 DTO。
- 简单查询/状态/事件内聚于页面；提取 hook 能解释收益，独立区块持有自己的闭环，无万能 hook/store 或仅透传包装组件。
- services 按域、入口 namespace；页面不直接 HTTP，传输层不依赖业务；没有猜测 envelope、假成功/伪接通或未授权业务 mock。
- 字段/静态配置、枚举值、表单转换与实际契约一致；样式隔离、alias 与测试解析真实可用，无无意义空目录。
- loading/空数据/错误明确，失败可恢复且输入不丢；旧请求身份保护、卸载清理、多消费者取消隔离；不以源码匹配测试替代运行时验证。
- 不默认 memo/useMemo/useCallback；effect 依赖真实稳定，不关闭 lint 逃避闭包问题；事件/计时器/观察器按生命周期清理。

## 按模式补验

| 模式 | 关键链路 |
| --- | --- |
| 简单状态/只读页 | 首次加载、刷新、异常、恢复、卸载；不生成编辑能力 |
| 查询表格 | 输入草稿 → 提交条件 → 页码重置 → 数据；空/错区分、重复查询、旧结果晚到；分页按契约 |
| 主从编辑 | 上下文/焦点有效性、详情竞争、新建/编辑初始化、保存失败保留输入、成功刷新与选择策略、脏数据切换 |
| 详情 | 无 ID、不存在、无权限、切换 ID、旧详情不伪装为新详情 |
| 选择表单 | 选项/联动加载与合法值、校验、DTO 转换、防重复提交、失败保留值 |
| 弹窗区块 | 打开/初始化/重开、焦点与键盘、保存中策略、关闭/取消、脏数据确认和回调 |
| 复合工作台 | 先确认状态所有者；上下文 → 主数据 → 焦点 → 面板；类型分派回退、独立区块错误、保存后联动与竞态 |

## 证据与交付
